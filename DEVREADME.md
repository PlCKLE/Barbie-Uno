HOW TO RUN NEW BARBIE UNO

Step 0: If you don't have it already, install node.js. https://nodejs.org/en
You can check by running this command: npm -version
If you don't see an error and see a version, you have node.js installed.

Step 1: Open a terminal, and change directory to barbie-uno (probably this command: cd barbie-uno)

Step 2:In that terminal, run this command: npm install

Step 3: In the terminal, run this command: npm run dev

Step 4: You're officially running the web server! Now, open the link. (Hold control, then left click the link)

Step 6: Open a new terminal (keep other open), and change directory to backend (probably this command: cd backend)

Step 7:In that terminal, run this command: npm install

Step 8: In the terminal, run this command: node server.js

You're good to go!
